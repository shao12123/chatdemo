V1 · 空态doc-empty

未打开任何文档：中央插画 + 「文档会显示在这里」。.doc.is-empty 时隐藏正文、对比条、更改开关。

V2 · 写入中is-writing

头部状态用品牌色「正在写入…」；正文写到一半 + 光标 + 骨架行；工具按钮禁用。

V3 · 多 Tabhas-tabs

打开 ≥2 份文档时出现 chrome 条（浏览器式标签）；.doc.has-tabs .doc-head 去圆角。无 Tab 时 chrome 与 stage-bar 隐藏。

V4 · 正文 + 目录条outline

常规文档态：左侧 .doc-outline（l2 / l3 / l4）+ 右侧正文。简化为 3 级。

V5 · 任务板分层show-task

stage-bar 切到「任务」：.layer.decision（三决定）+ .layer.story（页面行）。层最多两级，强调靠字重。

V6 · 对比结果板show-compare

两列对比：cmp-switch（全部 / 仅差异）· 差异药丸 · 行名列 + 左右 cell（右列 alt 蓝底）。需先经 paper_compare_pick 确认两份。

V7 · 历史 / compare-bar

左：版本列表浮层（.ver-pop）。右：历史态头部「返回」+ compare-bar（还原此版本 · 编辑记录 N/M · 上一项 / 下一项）+ 行内增删高亮。

V8 · 标注中 peekis-marking

文档台进入标注：.doc.is-marking 出现框选层 + 右侧 .mark-dock。完整标注形态（PPT / 课程）见 annotation_edit V8–V11。

V9 · 与 doc_entry 分界note

对话里的 .artifact 文档入口条 = doc_entry，不是本卡。本墙只画点击入口后在右侧展开的文档台（及其子面）。
