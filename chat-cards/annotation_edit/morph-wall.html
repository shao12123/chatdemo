PPT · preset = ppt

V1 · 标注关闭ppt

预览顶栏「标注修改」是唯一开关，此时未选中；幻灯片原样、演讲者备注可见。生成中此按钮禁用，文案「生成完成后再标注」。

V2 · 开启 · 空闲ppt

进入标注：预览框描边 #548BF9；顶部刘海（280×36）显示「0 个标注」，箭头与「修改」均不可用；幻灯片内容下移 44px。

V3 · 标注框 + popppt

拉出选区后：框外压暗，框描边 #3370FF，旁出现 .anno-pop（286 宽）。填了要求，pop 右下发送圆钮可点——发送 = 入队，不进对话。

V4 · 队列 1–Nppt

三条已入队：页上序号圆标（贴框左上外沿，贴边可被裁），刘海「3 个标注」，右侧白底圆钮（朝右箭头，即「修改」）可用。序号整稿连续。

V5 · 展开队列ppt

点刘海箭头展开 .anno-store-list（宽 280）：序号 + 要求；悬停行出现编辑 / 删除，渐变盖住被挡文字。列表不再套卡。

V6 · 已发送 / 锁定ppt

一次发送后：队列清空、页上序号去掉、刘海回「0 个标注」；对话新增一条用户消息——每条标注一张 54×54 圆角 12 截图 + 气泡写出要求。标注模式可保持开着，但队列为空。

V7 · 失败 → 错误卡片ppt

全部失败 / 部分失败都用全站 error_card 的 .net-card：浅灰无描边圆角 14 + 圆形叉号 +「重试」主按钮；禁止白底描边「重新生成」。部分失败卡片内放失败选区截图（54×54，不用页码标签）。重试不把标注画回预览，也不另开版本。

暂停：对话只写「修改已暂停。预览里不再保留这些标注。」，继续 / 暂停放输入框右侧（见右侧示意），不在对话里放按钮。

COURSE · preset = course_doc

V8 · mark-dock 空course_doc

文档台 .is-marking：正文十字光标，右侧 dock 标题「文档标注」+ 提示「在图上拖一个框，写下要改的地方。可标多处，最后一次发送。」，无发送按钮。

宿主文档台全貌见 course_paper V8。

V9 · N 条草稿course_doc

正文两处 .mark（蓝框 + 序号）；dock 里两条 .mark-item：序号、删除、textarea、上传文件 / 上传图片。底部「发送 N 处修改」（N = 有内容的条数）。

V10 · item.oncourse_doc

点 dock 的某条或点正文的框：.mark.on + .mark-item.on 同步描边 / 外圈。

V11 · 已发送只读course_doc

发送后 .mark.sent 变绿，dock 里 textarea 禁用、顶部只显示「已发送」，底部「本页批注已发送，框保留为只读。」。以对比面为例（该 surface 发送后保留框）。

V12 · 三种 surfacenote

同一 dock 套在文档 / 任务 / 对比三个面上，仅标题不同；发送后的框是否保留有差异。

surfacedock 标题标注层发送后
doc文档标注#marksLayer 覆盖 .doc-article框清空（回到未标注）
task任务标注#taskMarksLayer 覆盖任务板框清空
compare对比标注#compareMarksLayer 覆盖结果板框保留为只读（绿）

与 PPT preset 的区别：PPT 用顶部刘海收纳队列、pop 内联编辑；课程用右侧 dock 收纳草稿，发送按钮在 dock 底部。两者共用「先入队 / 草稿，再一次发送」语义。
