V1 · 代码变更摘要create + feedback

eyebrow「More 智能体 · 代码日志」→ 标题「变更摘要（N 项）」→ 说明 → is-key「改动」→ 说明 → 左下「创建」主按钮。卡外悬停行：赞 / 不感兴趣（可切换），时间戳悬停才出。

create：主按钮「创建」（plus 图标）→ 创建每日代码总结（Demo 占位）。feedback：feedback: true 才渲染卡外 thumbs；点已选再点取消；赞 / 不感兴趣互斥。时间戳 / 关闭键不出气泡（悬停气泡规范）。
字段：change（改动文案）· feedback · at。

V2 · 会议准备meeting

eyebrow「会议准备」→ 标题 → 开始时间 / 会议链接 → 可选「消息进展」（is-key）→「建议准备」（is-action）→ 来源 → 左下「发起视频会议」。

2a · 有消息进展（3 条，带引用链接）

2b · 无消息进展（会前暂无可靠关联材料）— progress 为空则整块不渲染

模块闸门：progress[] 有值才出「消息进展」块（有数据才渲染）。字段：title · time · link · progress? · prep。

V3 · 关联内容related

头部右上「打开飞书」次要操作 → 发言人 → is-key「意图」→ .mc-items 多条关联（单聊 / 文档 tag，每行可再打开）。无底部主按钮。

关联项 tag：单聊 灰底 · 文档 绿底（.is-doc）；描述两行截断。字段：title · speaker · intent · items[]（kind · title · desc）。

V4 · 飞书聊天知会notify

头部右上「打开飞书」→ 发言人 / 知会对象 → is-key「要点」。最短变体：无列表、无底部按钮。

字段：chat · speaker · notify · point。

V5 · 高频主题汇总canonical

标题 + 副标题 + 总览（主题色块 + 次数）→ 多主题分栏（序号徽标 / 次数 / 说明）→ 洞察（is-key）→ 建议（is-action，编号列表）→ 增量（is-extra，无底灰字）→ 左下「查看详情」。

多主题：topics[] 每项一个 .dr-topic，主题色只落在序号徽标与总览色块；主题间只用分割线（≤ 两层卡）。
边界：「查看详情」在源 Demo 打开右侧 .digest-view 简报；该右侧详情不进库（见 CARD_ID-NAMING.md E 区）。本墙只收 chat 卡本体，按钮仅占位。
