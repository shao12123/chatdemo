V13 · 多选preset

V14 · 多题 / 多字段preset

一卡内多组字段（对齐 conversations askCard 语义）。每组一小标题 + 选项行；底部仍一对 跳过/确认。

V17 · 对哪里不满意ask_form

来自 conversations.html renderRevise()：.pick-card + .choice radio 行 + 「自定义」行（.custom-box 输入）+ 「确认并生成」。选中预设或自定义非空才启用确认。

归属：同一 card_id: ask_form（host 补输入壳的第二套 DOM），不是 analysis_card，也不是 paper_compare_pick。确认后 host 自行锁定并收起卡（rev.locked）。

V18 · 多题步进ask_form

来自 askCard onboard（renderCard）：.pick-card + .steps 圆点（got / on）+ .choice 选项 + 上一步 / 下一步 / 确认并生成。墙内简化为 2 步（产品为 3 题）。

与 V15 同为「多题换题」语义，但 DOM 是 .pick-card（conversations 现行）而非天气 .ask。末步主按钮由「下一步」变「确认并生成」；首步「上一步」disabled。
