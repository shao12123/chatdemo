V1 · metric 壳canonical

verdict + facts + metrics + conclusion + chapters。可核对数字 / 实验对照。章节 Tab 在卡内切换，不强制开右侧。

卡外 tip 不在本卡画；见 tip_block 形态墙。操作栏 / 消息目录由 host 挂，不属于本卡。

V2 · points 壳

verdict + points + conclusion。规则 / 离散判断点；要点卡白底描边、略抬一层。

V3 · material 壳

fileCards（+ 可选总判断卡）。每页图一张「总结报告」：缩略图 + 标签 + 核心主题；第一张带合作对照。

V4 · spec 壳

verdict + fields + sections。设计 / 交互 / 禁止项规范；章节左侧品牌线。

V5 · ledger 壳

verdict + facts + table + sections。台账 / Excel；table 优先，表圆角 12 + 浅投影。

表模块入口判空：headers/rows 不全则不渲染；headers.length === rows[i].length 为校验项。

V6 · catalog 壳

verdict + facts + sections。技能 / 能力 / 目录分类；章节标题前圆点。

V7 · notes 壳

split: "points"：总判断卡（含 quotes）+ 每个要点各一张总结报告；外框虚线、偏速记；无指标格。

V8 · 多文件多外框

「帮我总结下这些文件里讲了什么」：每个附件各一张总结报告（.brief-report-list）。图旁缩略图用于图；docx / xlsx 无缩略图，未读内容用表。

本壳多外框：fileCards 每项一张 article.brief[data-shell=material]，data-sum-sec="report-N" 供消息目录跳转。

V9 · 模块闸门为空gate

tip.items = []、table.rows = [] → 模块返回空串，禁止空壳占位。下图 payload 与渲染结果同屏。

tip 有数据时才出卡外提示块；样式与交互以 tip_block 为准，本墙不再复制 tip 形态墙。
