V2 · 安排中状态

V3 · 已确认状态

状态改「已确认」；按钮灰禁用「已确认」；建议块转为正式色（面试蓝 / 午餐绿 / 已有灰）。

V4 · agenda 分日列表body 变体

把同一份建议按「日」分组成列表（时间 / 标题 / 标签），适合跨天或改期；头部与脚部同 timeline。

agenda_list 是 本卡别名，不另开 card_id。body: "agenda" 即可。

V5 · agenda + 选项条闸门

agenda 预览 + 下方方案选项。选项条（A/B 方案）语义是补输入，归 ask_form；此处仅示意与预览同屏。

实现：AI 先 present_schedule_preview（无脚部按钮）或 host 出 ask_form；用户选完后预览才带主按钮。选项高亮样式沿用 ask_form 壳，不单独维护。

V6 · 日期闸门闸门

缺日期时的二选一按钮组（本周四 / 下周四）——归 ask_form，不属于预览卡。

与 V5 同理；确认日期后再出 timeline / agenda。

V7 · 全部失败 · 重试异常

lead 说明 + 右下悬停重试图标（本墙强制露出）。保留 demo 的轻量失败 chrome，不是 error_card 的 net-card。
